## 👆 Try these first
- 🏠 **Home** — see what's happening right now, today and tonight
- 📅 **Events** — filter by Today / Weekend / This Week + category
- 💬 **Forum** — vote, comment, reply, save, follow
- 🏘️ **Town** — town updates, local places + reviews, and an **interactive map**
- 🎓 **University** — official updates (marked *University Verified*)
- 🔍 **Search** — events, posts, people, societies, places
- 🌙 **Dark mode** — toggle in the top‑right

## ⚠️ Important: this is a **DEMO**
Everything you see — the events, posts, town and university updates — is **sample (DEMO) data** generated to show the app working. **They are NOT real upcoming events, real people, or real university announcements.**

The *engine* is real: it automatically collects events from connected sources, auto‑categorises them, de‑duplicates them, and marks each one **University Verified / Verified / Imported / Community**. We just haven't wired up the live university / society / venue feeds yet — once connected, this is exactly where the real thing appears.
